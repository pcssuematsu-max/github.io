PHASE 1 / NxN FOUNDATION

一手ずつ、状態を確かめる。

手順を入力して再生できます。背景をドラッグすると視点が回ります。ステッカーを直接スワイプして回す操作は、ただいま準備中です。

NxN CUBE

このブラウザでは3D表示に必要なWebGLを利用できません。手順の確認には、対応ブラウザで開いてください。

RやUなどの外層回転、x / y / z、Rw（r）、3Rwなどのワイドターンが使えます。M / E / Sは、3×3・5×5・7×7で使えます。

STARTING STATE / SCRAMBLE

開始手順を表示

SOLUTION

ボタンで現在位置の後ろに手を追加し、そのまま実行します。

背景をドラッグして、好きな角度から見てください。キーボードでは、入力欄の外で Space を押すと再生・停止、← / → で前後へ移動できます。
