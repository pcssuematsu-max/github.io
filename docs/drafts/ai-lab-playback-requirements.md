# Rubiks_portfolio の手順をWebで再生するための必要事項

このファイルは、`Rubiks_portfolio` で扱っているパズルや手順を、Webサイト上で立体的に再生するための確認シートです。

- `【要入力】` と書かれた箇所に入力してください。
- 分からない場合は、`おまかせ` または `不明` と書いて大丈夫です。
- まずは **「最初に公開する1つの再生例」** だけを埋めれば作業を始められます。
- ここに書いた内容をもとに、Python側の手順表記をWeb再生用へつなぎます。

- `Rubiks_portfolio` 内で心当たりのある場所：同上

## 2. Webページでの見せ方

- 掲載場所：Twisty Puzzle AI lab内に新ページ
- 表示するタイトル：AIが見つけた3-cycleを再生する
- 画面に載せたい短い説明：こういう感じの3cycleや2-swap、parity-fixなどをAIに探索させることをメインでやっています。
- 表示したい操作：要入力：再生 / 一手戻す / 一手進む / 最初に戻す / 手順一覧
- 利用者がパズルをドラッグで回転できるようにする：はい
- 自動再生：再生ボタンで自動再生
- 再生速度：標準

## 5. 今回は決まっている方針
