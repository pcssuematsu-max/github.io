THE PRACTICE LOOP

計測する。振り返る。
次の練習を決める。

01

計測する

スペースキーまたはタップで、インスペクションからソルブまでを自然に計測。

02

残す

タイム、+2、DNF、パリティ、メモを種目ごとのログへ保存。

03

見つける

平均、標準偏差、Tier、推移から、伸ばしたいポイントを把握。

WHAT YOU CAN DO

キューブ活動を、
ひとつの場所に。

毎日の数ソルブから、多種目を巡る練習、大会の緊張感まで。続けるための道具を、少しずつ揃えました。

TIME & SCRAMBLE

計測に必要なものを、迷わず。

WCA風のインスペクション、公式スクランブル、展開図／3Dビューアを用意。自由に混ぜるモードも選べます。

ANALYZE

記録を、次の練習に変える。

Best、Ao5、Ao12、平均、標準偏差、Tier分布をパズルごとに確認できます。

CIRCUIT

今日は、何を回す？

複数種目を交互に回すメニューを作成。最近練習していないパズルも選べます。

ALGORITHM PRACTICE

手順を、回して覚える。

F2L・OLL・PLLや2x2、Pyraminx、Skewbの練習項目を、状態管理と一緒に記録。

TOURNAMENT

練習に、少しの緊張感を。

仮想チームと順位戦・勝ち抜き戦で対戦。地域予選から本戦を目指す大会も遊べます。

INSTALL AS AN APP

いつもの端末から、
すぐ開けるように。

CubeLogはブラウザで動くWebアプリです。対応ブラウザでは、ホーム画面やDockに置いてアプリのように使えます。

MAC

Mac

Safariなら共有メニューまたは「ファイル」から「Dockに追加」。Chrome / Edgeならアドレスバーのインストールアイコン、またはメニューから追加します。

WINDOWS

Windows

Chrome / Edgeのアドレスバーにあるインストールアイコン、または「…」メニューの「アプリをインストール」から追加します。

iPHONE / iPAD

iPhone・iPad

Safariで開き、共有ボタンから「ホーム画面に追加」を選びます。表示名を確認して追加すると、ホーム画面から起動できます。

ANDROID

Android

Chromeで開き、「︙」メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

記録を守るために

記録は基本的に使っている端末内に保存されます。端末を変える前や、まとまった記録ができたときは、アプリ内の「記録を守る」からバックアップを作っておくと安心です。
